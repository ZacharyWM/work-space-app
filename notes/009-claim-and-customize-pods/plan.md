# claim and customize pods and customize common areas

Users should be able to claim and customize a POD. PODs are the only zones that can be customized.
This means we need a library of things like chairs, desks, rugs, plants, artifacts and more so we can make the space more fun and interesting. Feel free to add some qirky decor in there as well.
Anyone should be able to drag and drop from the library into the space ship.
Anyone should be able to delete an item (but don't make it too easy to accidently delete).
Even when a person logs out, a person's name will be on (or above or below) their POD somewhere. A user can't claim an already claimed POD.

Update @notes/009-claim-and-customize-pods/progress.md with all progress and decisions made.
