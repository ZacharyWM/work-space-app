# User statuses and wave

## User statuses:

Users need statuses that are visble to all other users: available, busy, and away.

## Wave

You should be able to target and wave at any other user that is logged in. Waving will give the user being waved at a "ping" or some kind of notification sound, and maybe a visual indicator too if you have any good ideas for how that will work.

## Other instructions:

The ClaudeDesignPrototype files don't have prototypes for these features, so you can design it however you think best.
Put all your decisions and progress in the @notes/004-status-and-wave/progress.md file.
