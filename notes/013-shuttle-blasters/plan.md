# Shuttle Blasters game

This is like the shuttle racing game as described in @notes/012-space-ship-racing/progress.md, but instead of racing, we shoot lasers at each other. As soon as you get blown up, you're out of the game. The last person that isn't blasted is the winner. It only takes 1 blast to destroy a shuttle.

Put a shuttle blasters option in the map editor.

Update @notes/013-shuttle-blasters/progress.md with all your progress and any decisions made.
